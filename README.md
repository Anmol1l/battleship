# Battleship

A browser-based implementation of the Battleship game.

## Live Demo

[View Live Demo](https://anmol1l.github.io/battleship/)

## Features

- Player vs Computer
- Local two-player mode
- Drag-and-drop ship placement
- Random ship placement
- Computer opponent with basic hit-based targeting logic


## Technologies Used

- JavaScript
- HTML
- CSS
- Webpack
- Jest

## Testing

- Developed using Test-Driven Development (TDD).
- Unit tests written with Jest for game logic.

## Future Improvements

- Improve computer AI targeting strategy
- Add Support for Mobile devices
